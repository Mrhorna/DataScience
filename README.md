# DataScience

Repositorio de ciencia de datos.

## Proyectos

- [`habit-tracker/`](habit-tracker) — Dashboard web para hacer tracking de hábitos diarios (rachas, % de cumplimiento, calendario de constancia y tendencia semanal). Sin backend: los datos se guardan en el navegador. Para usarlo, abre `habit-tracker/index.html` o sírvelo con cualquier servidor estático.
